# Maui 101 Getting Started
To run locally, create a copy of config.json under Resources/Raw/ and rename it config.local.json, and then update the APIKey value to a real API Key for api.thecatapi.com. 

Tested using Android Studio only. If you are also using Android Studio to test, and are testing on a corporate machine, you'll need to install the root cert on your virtual device in order for the API requests to work properly. To do this, you'll need to copy the root cert to the device, and then install the cert by going to Settings → Security (or "Security & privacy") → More security settings / Encryption & credentials → Install a certificate → CA certificate on the virtual device.

If you need an API Key or the root cert, please contact me and I can get that for you.
